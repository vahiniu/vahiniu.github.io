Things I've built

Startups, apps, some hardware, and a bit of research.

Buy vs Rent explorer

My husband and I toured five open houses one Saturday and still couldn't tell how much house we could actually afford, or whether buying even beat renting. Every relative swears a home is "an investment," so we built this to see the real math: plug in the numbers and it shows the break-even.

Interactive tool · Live

TriageBridge

A weekend build: a health app that actually triages you. You tap where it hurts, describe what's going on, and it sorts the symptom into emergent, urgent, or routine, then pushes the serious ones to a real physician's queue. Plus meds, goals, and live "what-if" risk scores on the side.

Side project · Health app

WanderYou

Planning a group trip is chaos, so I built an app for it. Everyone swipes to vote on destinations, then Claude spins up the itinerary, packing list, and a local cheat sheet. It's live, go try it (and break it).

React · Claude API · Live app

Direction-of-arrival estimation in realistic radar

My master's thesis. I pitted the classic radar direction-finding algorithms (matched filter, MUSIC, compressed sensing) against messy real-world multipath and noise, then trained a denoising autoencoder to claw the accuracy back.

M.S. thesis · Radar signal processing

Chipless RFID: low-cost tags & localisation

My undergrad thesis: an RFID tag with no chip and no battery, the data lives in the tag's shape, plus a radar trick to work out where the tag actually is. It ended up winning best B.Tech. project in my batch.

RF design · Best B.Tech. Project

Radar image denoising with autoencoders

I trained autoencoders to clean up radar images distorted by walls, messy in, sharp out. It became my first published paper, at IEEE RadarConf 2018.

Machine learning · IEEE RadarConf

Non-invasive glucose sensing

A weekend-curiosity build, an Arduino wearable (PPG, skin response, temperature) to see if you could ballpark blood glucose without the finger prick. Spoiler: harder than it looks, but I learned a ton.
