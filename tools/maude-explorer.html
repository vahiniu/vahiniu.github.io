openFDA API key — optional, but read this before a big run
Without a key openFDA allows 1,000 requests per day from your IP address, and a full run uses roughly 100–150. With a free key that becomes 120,000 per day. The key is stored only in this browser (localStorage) and is sent only to api.fda.gov. Get one at open.fda.gov/apis/authentication.
